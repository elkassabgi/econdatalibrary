From Phase-2b classification (2026-06-23). 120 sources raised open questions/risks.

These are the per-source decisions/risks to resolve while implementing each adapter.

## Hard blockers (source produces nothing until fixed)
- **cow** (bulk_snapshot_if_changed): Per-dataset version bumps require editing filenames; want an automated probe of likely next versions (NMCv8, COW_Trade_5.0) plus alert-on-404? Also alliances/states have hard-coded end-year caps (2016/2025) that may truncate recent years on a new release.
- **gpi** (overwrite_if_changed): BLOCKER: all 9 hardcoded GPI_URLS return 404, so the source produces no parquet and exits success silently. Need a working IEP/OWID GPI URL before any strategy can run — please supply the current download link.
- **spi** (manual_vintage): Keep this script or ingest_social_progress.py (they clobber the same spi/spi.parquet)? And supply a current working SPI download URL, since all hardcoded URLs are 404.
- **tcmb** (extend_by_date): Persist non-trading-day 404s to a skip-set and switch checkpoint writes to temp+rename (current in-place pq.write_table has a small crash-time data-loss window) — improvements, not blockers.
- **whr** (overwrite_if_changed): COVERAGE BLOCKER: current output is only the ladder slice because all 6-factor S3 XLSX panels 403 and 6/7 OWID CSVs 404 — need a human to supply working panel URLs/Referer before any refresh, and the overwrite must compare obs counts so a thin pull doesn't clobber a richer prior file.
