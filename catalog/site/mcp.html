Use this library inside Claude, Cursor & other AI tools

The ElkassabgiData MCP server exposes the whole data-library family — Econ Data Library (billions of economic series) and HF Data Library (1-minute US equities) — to any AI assistant that speaks the Model Context Protocol. Your assistant can search the catalog, fetch series with their citations and licenses attached, check live data freshness, and run guided analyses, all inside a conversation.

Connect in two minutes

  1. Claude (web/desktop): Settings → Connectors → Add custom connector → paste the URL below.
  2. Cursor / other MCP clients: add a remote MCP server with the same URL.
https://elkassabgidata-mcp.elkassabgi.workers.dev/mcp?api_key=YOUR_API_KEY

Replace YOUR_API_KEY with your free ElkassabgiData key — the same key used on hfdatalibrary.com (one account for every library). Prefer headers? Send it as X-API-Key or Authorization: Bearer instead of the URL parameter.

No key? Everything except data downloads still works — search, metadata, sources, freshness, and status are open. Downloads return a friendly pointer to the free registration. Your key is used server-side only and is never echoed into the AI conversation.

Resources & guided prompts

The server publishes MCP resources your assistant can read: a data-honesty charter (survivorship caveats, the 2022 source break on HF data, per-source licensing, freshness semantics — so analyses disclose what they should), the variables dictionary, and a family overview. Guided prompts ship ready-made workflows: analyze_econ_series, compare_countries, and hf_event_study — each bakes the honesty rules in (no interpolation, citations required, caveats disclosed).

Try asking your assistant

  • “Search ElkassabgiData for German inflation and plot it against French inflation since 2000.”
  • “What's the data freshness for the ECB source in econdatalibrary?”
  • “Download AAPL 1-minute bars via ElkassabgiData and run an event study around 2024-08-05.”

Fair use

MCP traffic uses the same account, rate limits (300 downloads/min), logging, and licenses as the website APIs. Per-series licenses travel with every response — please honor them, especially the non-commercial sources, and keep the attribution lines in published work.
