Storage layout
one parquet per TABLE under a per-provider dir: data/clean_full/<provider>/<table_path with / -> __>.parquet (DST: DST__<id>.parquet). 5-column schema provider/table_id/series_key/obs_date/value (wider than the 3-col schema of the other scripts). Counts on disk vary by provider (e.g. dst 705, ssb 186, statfin 135, scb 9, cso 44, bfs 1). ssb/statfin also write _catalog.json; several dirs carry _<provider>_log.txt/_err.txt.

Full description

Generic PxWeb ingest -- covers SCB (Sweden CC0), SSB (Norway CC BY 4.0), Statistics Finland (CC BY 4.0), Statistics Denmark StatBank (CC BY 4.0), CSO Ireland (Open Gov), FSO Switzerland (Swiss OGD). PxWeb is an open-source API used by Nordic and other NSOs. All return JSON-stat or custom JSON with the same query model. Run: python jobs/ingest_pxweb.py <provider> providers: scb ssb statfin dst cso bfs SCB (Sweden): https://api.scb.se/OV0104/v1/doris/en/ssd/ SSB (Norway): https://data.ssb.no/api/v0/en/ StatFin (Finland):https://pxdata.stat.fi/PXWeb/api/v1/en/ DST (Denmark): https://api.statbank.dk/v1/ CSO (Ireland): https://data.cso.ie/api/v1.0/ BFS (Switzerland):https://www.pxweb.bfs.admin.ch/api/v1/en/ License: CC0 (SCB), CC BY 4.0 (SSB, StatFin, DST), Open Gov (CSO, BFS)
