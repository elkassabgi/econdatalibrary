Full description

GUS Poland — Bank Danych Lokalnych (BDL), national-level, 1999–present. License: Open data (CC BY 4.0, GUS public data policy) Source: https://bdl.stat.gov.pl/ No API key required. Coverage: * 172,563 variables across 33 subject domains * National-level (Poland total) annual data, 1999–present * Prices, employment, wages, GDP, trade, demographics, housing, etc. Strategy: * GET /api/v1/subjects → crawl K→G→P hierarchy * For each P-level subject (hasVariables=true): GET /variables?subject-id={P} * For each variable: GET /data/by-variable/{id}?unit-id=000000000000&level=0 * Checkpoint every 500 variables per K-subject * One Parquet per K-level subject (top 33) Run: python jobs/ingest_gus_bdl.py
